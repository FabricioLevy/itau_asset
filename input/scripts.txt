# ═══════════════════════════════════════════════════════════════════════════
# Uma linha por script:
#
#     Nome | caminho do script.py | argumentos | pasta de output
#
# - Argumentos e pasta de output são opcionais. Sem argumentos mas com
#   output, deixe a coluna vazia:   Nome | script.py |  | C:\pasta\output
# - Linhas que começam com # são ignoradas.
# - Caminhos (script e output) podem ser absolutos (C:\...) ou relativos
#   à pasta src/.
# - Só o caminho também funciona: o nome vira o nome do arquivo.
# - Cada script roda com a própria pasta como diretório atual, então os
#   caminhos relativos dentro dele (../input, ../output) continuam valendo.
# - Os argumentos podem ser alterados no painel antes de clicar em RODAR.
# - O botão "Output" do painel abre a pasta de output no Explorer.
# - Depois de editar este arquivo, clique em "Recarregar lista" no painel.
